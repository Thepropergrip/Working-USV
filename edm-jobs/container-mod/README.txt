TPG 10FT SHIPPING CONTAINER - OPEN (LITE) v1.0.0

INSTALL
Copy the folder "TPG_10FT_CONTAINER_OPEN_LITE" into:
  Saved Games\DCS\Mods\tech\
(or Saved Games\DCS.openbeta\Mods\tech\ on installations still using that folder name)

MISSION EDITOR
Statics / Fortifications
Display name: TPG 10ft Shipping Container - Open (Lite)

BUILD NOTES
- Native Eagle Dynamics EDM export
- Approx. 15,000 visual triangles, reduced from ~715,800 source CAD/STL triangles
- Simple body-only collision shell
- Meter-scaled and ground-aligned
- Compact 1024px native ED PBR painted-steel texture set (Base / RoughMet / Normal)
- Unique plugin/unit/model identifiers; designed to coexist with other TPG mods
- Open doors are visual geometry and deliberately excluded from collision
